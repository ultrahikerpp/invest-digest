### 各主題重點

#### 主題一｜DeepSeek 時刻 2.0 來了？

- 作者提到，中國新創「月之暗面」（Moonshot AI）發表旗艦模型 Kimi K3，擁有 2.8 兆參數，在多項獨立評測擠進全球前四，並在前端網頁代碼編寫等特定領域擊敗 Claude Fable 5 與 GPT-5.6 Sol，Bloomberg 以「中國的 Moonshot 帶來新的 DeepSeek 時刻」為題報導。

- 作者認為關鍵在於架構創新：Kimi K3 採用極致的混合專家架構（MoE），像一家有 896 位專家的顧問公司，但每次提問僅調用其中最合適的 16 位，以「極度稀疏」方式兼顧 2.8 兆參數容量與運作效率；並配備 100 萬 Tokens 超大上下文與自主代理（Agent）能力。

- 作者指出帳面定價便宜（每百萬字輸入 3 美元、輸出 15 美元，約與 GPT-5.6 Terra 相當），但實測是個「話癆」：據 Artificial Analysis，完成相同任務產生的字數幾乎是其他模型平均值的兩倍，折算後實際任務成本與昂貴的 GPT-5.6 Sol 相差無幾。

- 作者認為它「不完全」是另一個 DeepSeek：當年 DeepSeek 走極致價格破壞路線，Kimi K3 則定價顯著高於國內同行，選擇在技術難題上硬碰硬，主打大體量、超長上下文與原生多模態視覺，證明中國實驗室有能力做出性能頂尖的旗艦模型。

- 作者提到月之暗面承諾 7 月底完全開源權重，這個接近 3 兆參數的工具將變成免費資源，屆時會倒逼收取高昂訂閱費的西方閉源巨頭拿出更具革命性的產品。

#### 主題二｜Kimi K3 對模型兩大巨頭的影響？

- 作者認為 Kimi K3 最重要的核心價值在於「開源」，而非又一個普通模型選項；它是歷史上第一次有團隊將極度接近頂尖水準、具 100 萬超長上下文與原生視覺的巨無霸模型直接送進開源社群，可能終結「開源模型不夠強」的時代。

- 作者指出受影響最大的是靠販售 API 為生的 OpenAI 與 Anthropic：當出現一個聰明程度達最頂尖模型 90%、卻能自行部署、成本極低又保證數據不外洩的開源模型，將直接動搖閉源巨頭的定價權；其中以「寫程式最強」為賣點的 Anthropic 承受壓力尤為明顯。

- 作者認為雲端巨頭其實樂見「模型碎片化」與開源崛起：若閉源被 1～2 家壟斷，微軟、亞馬遜恐淪為只提供電力與伺服器的「水電工」；反之天下大亂、群雄割據時，雲端巨頭才能靠「模型調度與管理」牢牢掌握客戶關係，賺取平台管理費與算力費，這也是 AWS 對支持開源模型最積極的原因。

- 作者認為這不會是「一夜變天」：下載 2.8 兆參數模型不代表能在筆電流暢運行，仍需龐大專業硬體，多數中小企業與個人開發者最終仍得依賴雲端託管；且 Kimi K3 在某些綜合智力指標與最頂尖閉源模型仍有差距，開源授權也可能有商業限制。

- 作者強調其真正意義在於打破西方閉源巨頭對「前沿能力」的壟斷，給了企業客戶更多籌碼與選擇，成為一個分水嶺。

#### 主題三｜Kimi K3 會令 AI 支出減少嗎？

- 作者的結論相反於華爾街的「AI 泡沫要破、算力見頂」恐慌論述：他認為模型層利潤縮水，往往是底層基礎設施與上游應用迎來更健康爆發的前兆。

- 作者以馬拉松比喻「領跑者壓力」：當對手（開源模型）換上更高效跑鞋逼近，OpenAI、Anthropic 理性選擇是加速訓練更大更強的下一代模型，這是一場停不下來的軍備競賽，研發與訓練算力投入只會增加。

- 作者指出巨頭有「能力」燒錢：微軟、亞馬遜、Google 給實驗室的投資很大一部分以「雲端算力額度」（Cloud Credits）形式支付，資金轉化為 Azure 或 AWS 營收，形成閉環、降低現金流壓力並撐大雲端業務；巨頭最完美的劇本是既讓前沿實驗室有資金推進極限，又透過自家模型與開源勢力施壓「純模型層」，避免其壟斷暴利、脫離掌控。

- 作者引用「傑文斯悖論」（Jevons Paradox）：當 Token 價格暴跌 50%，企業反應不是省一半預算，而是把 AI 塞進以前不敢嘗試的場景；多模型路由、多代理反覆對話、長思考鏈會帶來成百上千倍的 Token 消耗，整體推理算力（Inference Compute）需求反而更巨大爆發。

- 作者認為產業正步入成熟，重心發生兩大結構性轉變：價值向上下游（算力基礎設施、編排層與工具鏈）轉移，以及焦點從「哪家模型最強」轉向「如何靈活組合不同模型解決真實複雜問題」的系統工程，類比網際網路早期基礎設施變便宜後催生搜尋引擎與電商。

#### 主題四｜微軟：別讓模型公司偷走你的數據？

- 作者提到，身為 OpenAI 最大金主的微軟 CEO Satya Nadella 公開呼籲企業「小心別被模型廠商洗劫了數據」，看似左手打右手，實為重新定義 AI 遊戲規則。

- 作者引述 Nadella 提出的「逆向資訊悖論」（The Reverse Information Paradox）：Kenneth Arrow 的原始資訊悖論中承擔風險的是賣方，但 AI 時代反過來，承擔風險的變成付費使用 AI 的企業（買方）。

- 作者說明其含義：員工使用 AI 並修正錯誤答案時，企業付了兩次代價——一次是 Token 費用，一次是把最珍貴的內部運作經驗免費送給 AI；長此以往模型廠商越來越懂你的行業，你對黑盒子卻一無所知，差距越拉越大。作者提到這與 Palantir 執行長 Alex Karp 的發言遙相呼應。

- 作者介紹微軟在 Build 大會推出的「Frontier Tuning」：在企業專屬 Azure 邊界內建立私有「強化學習環境（RLE）」，由三核心構成——與生產系統隔離的安全沙盒、導入企業專屬數據（如 SharePoint、Microsoft 365）並記錄員工真實決策與糾錯軌跡、優化後的模型參數與學習記憶完全保留在企業自己的 Azure 環境不外流。

- 作者認為微軟策略核心是將商業模式從低毛利「代幣銷售」升級為「系統平台」，順應金融、醫療對數據主權的剛需，把核心學習閉環鎖進 Azure，未來極難轉移；「既賣矛、又賣盾」讓微軟立於不敗之地——模型是流水的兵，Azure 才是鐵打的營盤。

#### 主題五｜從蘋果起訴 OpenAI，看 AI 時代的終端入口之爭

- 作者以蘋果訴狀細節（Jony Ive 的硬體新創、超過 400 名被挖角的蘋果硬體團隊成員、面試中被要求展示的未公開原型零件）指出，蘋果與 OpenAI 已無退路；2024 年夏天雙方還宣布將 ChatGPT 整合進 Apple Intelligence，兩年後 OpenAI 卻成為蘋果必須全力阻擊的對手。

- 作者認為衝突根源在於 OpenAI 從「軟體互補品」轉變為「硬體替代品」：2025 年以約 65 億美元收購 io Products 並挖角超過 400 名蘋果硬體成員，試圖打造 AI 原生硬體載體、直接建立與用戶的互動，削弱用戶對 iPhone 作為主要 AI 入口的依賴，觸碰蘋果最核心利益。

- 作者解釋為何蘋果轉向同樣擁有硬體與 OS 的 Google 合作：這揭示「老巨頭」與「新貴」的矛盾。蘋果與 Google 各有無可動搖的地盤、彼此利益綁定（如 Google 每年付蘋果高達數百億美元維持 iPhone 預設搜尋地位），有極高的「相互保證毀滅」成本，傾向在既有規則下合作共生。

- 作者認為 OpenAI 是沒有歷史包袱、試圖重塑版圖的新貴：意識到單純擁有模型層不夠，沒有分發通路就可能淪為巨頭生態的「打工仔」，因此必須擁有自己的硬體與通路，這種「掀桌子」的侵略性是蘋果無法容忍的，須在其硬體羽翼未豐前徹底阻擊。

- 作者主張真正護城河重回「系統層」而非「模型為王」，理由有三：入口的排他性（誰控制裝置就控制注意力、上下文數據與流量分發權）、數據的護城河（端側運算與私密雲端運算結合，基於硬體安全晶片建立信任）、獲利模式的穩定性（硬體替換週期與高轉換成本提供穩定現金流與生態黏性）。本質是一場時間賽跑：OpenAI 須在模型溢價消失前做出硬體，蘋果則試圖以訴訟拉高其開發成本、拖慢進度。

#### 主題六｜CoreWeave 竟然「做空」供應商？

- 作者提到 AI 雲端服務商 CoreWeave 正與投資銀行研議，考慮將買進美光、SK 海力士等股票賣權（Put Options）納入潛在選項，反手「對沖核心供應商股價」作為避險手段。

- 作者說明動機是長期合約的「價格下限」（Price Floor）風險：記憶體供需緊繃下美光開始簽三到五年長期供應合約（LTA），保護供應商的價格下限條款使買方即使未來現貨價回檔仍須按最低保證價採購；若記憶體暴跌，CoreWeave 將被長約綁死、毛利率受損並面臨庫存跌價損失。

- 作者指出這符合創辦團隊人設：Michael Intrator、Brian Venturo 與 Brannin McBee 具深厚大宗商品與能源交易背景、曾管理天然氣對沖基金，視 GPU 與記憶體晶片為「大宗商品」、算力中心為需鎖定輸入成本的「加工廠」，一向擅長結構化融資，如今自然拿出最熟悉的金融避險（Hedging）武器。

- 作者以航空業油價避險類比並點出其局限：航司用直接對應的原油期貨，CoreWeave 卻用記憶體廠商的「個股賣權」，股價與實際晶片價格存在落差、避險不夠精準；且個股衍生品流動性有限、大額避險成本極高，暴露半導體產業鏈缺乏像原油、黃金那樣高流動性、能直接對沖實物價格的標準化工具。

- 作者認為此消息對記憶體大廠影響微妙：正面看，代表買方認真專業對待長約、不會事後賴帳毀約，若 CoreWeave 在金融市場賺到錢便能繼續履約，增加營收確定性；負面看，市場一旦傳出大額賣權買單，等於宣告「大客戶預期晶片將大跌」，可能在景氣循環末端對晶片大廠股價造成額外下行壓力。作者整體評價這是一種成熟的商業契約精神，若試驗成功將為半導體供應鏈提供利用衍生品作為緩衝墊的全新範本。

### 核心觀點

- 作者認為「市場大跌時才是研究 ROI 呈指數級上升的時刻」：牛市中好壞公司齊漲、基本面研究價值被動能與情緒稀釋；崩盤時好公司被無差別錯殺，價格（Price）大幅偏離價值（Value），才是研究能產生最大 Alpha 的時刻。作者並提出實務框架——冷靜審視資產配置，區分「砍掉（基本面轉壞、核心敘事破滅）／保留（核心競爭力未撼動、僅被情緒錯殺）／加碼（長期趨勢明確、市場給出合理估值）」。

- 作者認為「模型層利潤縮水，是底層基礎設施與上游應用更健康爆發的前兆」：搭配傑文斯悖論（Token 變便宜反而催生爆發性新需求）與軍備競賽邏輯，推論整體推理算力需求會更大爆發，產業價值向上下游轉移、重心由「單一模型最強」轉向「系統工程」。

- 作者認為 AI 時代真正的護城河與價值正從「模型層」重新回到「系統層／平台層」：無論是微軟用 Frontier Tuning 把企業核心閉環鎖進 Azure，或蘋果捍衛「裝置層」的入口排他性，都指向掌握入口、數據主權與分發通路者，比純粹擁有最強模型者更具長期優勢。

### 關鍵數據

- Kimi K3：2.8 兆參數（文中亦以「接近 3 兆」描述）；MoE 架構共 896 位「專家」，每次調用其中 16 位；上下文窗口高達 100 萬字（Tokens）。

- Kimi K3 帳面 API 定價：每百萬字輸入 3 美元、輸出 15 美元（約與 GPT-5.6 Terra 相當）。

- 據 Artificial Analysis 實測：完成相同任務，Kimi K3 產生的 Output Tokens 幾乎是其他模型平均值的兩倍，折算實際任務成本與 GPT-5.6 Sol 相差無幾。

- 開源時間點：月之暗面承諾 7 月底完全開源 Kimi K3 權重。

- 評測排名：Kimi K3 於多項獨立評測擠進全球前四。

- 台積電：宣布將 2026 年資本支出進一步調高至 640 億美元。

- 開源模型能力假設值：作者以「聰明程度達最頂尖模型 90%」作為論述情境。

- 微軟 Frontier Tuning 早期客戶 Land O'Lakes：複雜報告準確度提升至九成以上，代幣消耗效率提高將近十倍。

- OpenAI：於 2025 年以約 65 億美元收購 io Products；挖角超過 400 名蘋果硬體團隊成員。

- Google 向蘋果支付高達數百億美元，以維持 iPhone 預設搜尋引擎地位。

- CoreWeave 相關：美光開始簽三到五年長期供應合約（LTA）；作者以「Token 價格暴跌 50%」作為傑文斯悖論的說明情境。

### 創作者建議的觀察方向

- 作者建議在資產配置上不要把所有資金重壓在半導體，分一些到大型科技股會安全一些（文中明言此為幾週前已提醒的立場）。

- 作者建議把「電子報／深度分析點閱率」視為一個反向指標，並在市場下跌時反而靜下心研究，用「砍掉／保留／加碼」框架重新審視持股。

- 作者提示留意 Kimi K3 未來開放「推理深度」調整後，性價比優勢是否真正釋放（即「每美元能買到多少有效智慧」此一核心指標）。

- 作者提示關注產業結構性轉變：價值向算力基礎設施、編排層與工具鏈等上下游轉移，以及從「單一模型」走向「系統工程／多模型協作」。

- 作者提示留意微軟 Frontier Tuning 與 Palantir 推動的「數據主權」趨勢，以及此對純模型廠商定價權的削弱。

- 作者提示觀察 CoreWeave 晶片避險試驗的後續：若成功，可能為半導體供應鏈建立以衍生品作緩衝的新範本；同時留意大額個股賣權買單傳出，是否在半導體景氣循環末端對美光等晶片股造成額外股價壓力。
