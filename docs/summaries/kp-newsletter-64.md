# Anthropic的增長令人失望？特斯拉造飛天車？長鑫搶記憶體市佔？ - KP思考筆記(第64期)

🔗 [閱讀原文於 Substack](https://www.fomosoc.com/p/anthropic-kp64)

## 本期主題總覽

- 長鑫存儲搶發 4F² 記憶體，要搶三巨頭的份額了嗎？：中國記憶體技術突破、DRAM競爭格局與量產門檻。
- Anthropic 賺了錢，市場卻嫌它長得不夠快？：AI企業營收成長放緩、獲利能力改善與IPO估值調整。
- ASML 有單子也先不接？：EUV設備供不應求、設備漲價、維修服務收入與半導體產能過剩風險。
- 特斯拉造了一輛會飛的車，股價就能飛嗎？：新一代Roadster的品牌價值、工程能力展示與商業化限制。
- 台積電為何外包產能給格芯？：CoWoS先進封裝產能瓶頸、製造資源配置與美國供應鏈本土化。

## 各主題重點

### 主題一｜長鑫存儲4F²記憶體與DRAM競爭格局

- 4F²架構突破設備限制：文章提到，長鑫存儲計畫年底前推出採用4F²架構的伺服器級DDR5記憶體，透過垂直通道電晶體、環繞式閘極與晶圓級混合鍵合技術，將記憶單元面積由6F²縮減三分之一，理論上提升30%至50%的位元密度，降低對EUV設備的依賴。
- 高毛利伺服器記憶體面臨潛在競爭：作者認為，市場擔憂長鑫進入DDR5 RDIMM市場，可能打破三星、SK海力士及美光的寡占結構與定價紀律。由於三大廠將產能轉向HBM，伺服器DDR5供應緊張、毛利率較高，潛在新增供給容易引發股價修正。
- 商業量產仍有三大障礙：文章指出，新架構必須克服良率與成本控制、Intel及AMD平台認證和雲端客戶驗證，以及基礎製程落後等問題。長鑫尚未公布產品速度、容量、製程節點及良率，年底推出的可能只是工程樣品。
- 短期業績衝擊有限：作者認為，長鑫真正通過驗證並取得大型客戶量產訂單，可能要到2027年甚至2028年之後，因此對記憶體三大廠短期業績影響有限。
- 長期供需結構值得注意：作者強調，長鑫全球DRAM營收市佔已接近10%，顯示中國廠商即使受到設備出口限制，仍能透過工程創新及內需市場提升競爭力，未來可能成為標準型記憶體價格週期的重要變數。

### 主題二｜Anthropic營收放緩、獲利改善與IPO估值

- 營收高速成長仍無法滿足估值預期：文章提到，Anthropic第三季營收達168億美元，季增45%，毛利率85%，自由現金流轉正。但部分潛在IPO投資者開始討論，將上市估值從2兆美元下調至1.5兆美元，反映公開市場重新檢視高成長AI企業的合理定價。
- 營收減速存在三項原因：作者指出，包括營收基數擴大、Token價格自2025年初以來下降68%造成短期收入壓力，以及Anthropic主動切斷約占營收5%至7%的競爭對手模型蒸餾相關API收入。作者認為，這些因素不完全代表終端AI需求衰退。
- 算力變現效率顯著改善：文章指出，Anthropic每投入1美元算力成本所創造的收入，從2025年的0.63美元提升至2026年第三季的1.70美元。作者認為，這代表公司逐漸從依賴外部融資的燒錢模式，轉向具備自我造血能力的商業模式。
- 高毛利率仍需審慎解讀：作者提醒，85%的毛利率未包含持續訓練下一代模型的研發投入，而11%的調整後營業利潤率排除了員工股權獎勵（SBC）。正式招股書公布前，仍須審慎評估真實獲利能力。
- IPO定價影響整個AI基建產業：作者認為，Anthropic上市估值是市場衡量AI需求與算力投資的重要訊號。估值下修短期可能壓抑CoreWeave等算力基建股，但合理降溫有助於重新校準市場預期，讓投資者更重視現金流與單位經濟效益。

### 主題三｜ASML設備定價能力與半導體資本支出週期

- 設備供不應求，但暫緩長期接單：文章提到，ASML的2027至2028年機台產能已供不應求，部分客戶甚至希望預訂2029至2030年的設備。作者指出，ASML暫不接受正式訂單，是為了掌握整體需求、合理分配產能，並保留未來定價彈性。
- 掌握關鍵技術帶來漲價能力：作者認為，ASML希望重新分配AI產業鏈的獲利，透過提升設備產出效率與價值導向定價，推動核心量產設備自2027年開始漲價，並於2028年全面反映。
- 既有設備服務成為高價值收入來源：文章指出，ASML第三季已安裝機台管理業務營收達33億歐元，第四季預估37億歐元。隨著客戶提高既有設備利用率，升級套件、維修零件及耗材需求增加。韓國科技圈亦傳出ASML計畫自2027年起調漲部分客戶維修零件價格10%。
- 訂單熱潮可能包含提前卡位與過度投資：作者認為，半導體業者為避免未來設備不足，可能提前下單；同時，晶圓代工與HBM業者各自按照樂觀需求預測擴產，最終可能造成產業總供給超出實際需求。
- 2030年前後需警惕產能過剩：文章引用SEMI預測，全球晶圓廠設備支出將在2029年達到2,270億美元高峰，2030年下降6%。作者提醒，設備支出下降不代表既有產能消失，2028至2030年陸續開出的新增產能，可能讓市場從供不應求轉為供給過剩。

### 主題四｜Tesla Roadster飛行展示與品牌估值敘事

- Roadster定位不是大量銷售的交通工具：文章提到，Tesla於10月15日在SpaceX德州測試場展示新一代Roadster，包括Performance、Thrust及具備飛行展示能力的Rocket三種版本，量產目標為2028年。
- 直接財務貢獻相對有限：作者指出，即使Roadster每年銷售數千輛，估計每年營收也只有數億至十幾億美元。相較Tesla約700億美元年營收及超過1兆美元的市值，Roadster對整體財務影響有限。
- 核心價值是品牌與工程能力展示：作者引用Morningstar分析師的「光環車」概念，認為Roadster的目的在於強化市場對Tesla工程能力的認知，進一步影響投資者對自動駕駛、Optimus機器人及能源業務的期待。
- 產品承諾與實際交付存在落差：文章指出，Roadster自2017年首次亮相，原定2020年交付，如今延至2028年；續航目標也從620英里降至300英里。作者認為，這凸顯Elon Musk產品承諾長期延遲的問題。
- 品牌敘事不等於直接獲利：作者認為，飛行展示更像是向投資人及競爭對手傳遞Tesla仍具備技術突破能力的訊號，而非證明Roadster能成為重要營收來源。

### 主題五｜台積電外包格芯與CoWoS產能瓶頸

- 以五年合約取得外部中介層產能：文章提到，台積電與格芯簽訂20億美元、為期五年的合作合約，由格芯紐約馬爾塔廠生產CoWoS先進封裝所需的矽中介層，預計2028年上半年量產。
- 將成熟製程工作轉移，保留先進製程資源：作者指出，矽中介層通常使用約65奈米成熟製程，但占用大量12吋晶圓產能。委託格芯生產，有助台積電將資源配置至利潤較高的N3及N2先進製程。
- 合作反映先進封裝長期供給緊張：作者認為，魏哲家承認後端產能短缺，加上CoWoS封裝尺寸從5倍光罩面積朝9倍、14倍擴大，代表矽中介層需求將持續增加。由於格芯2028年才量產，這項合作主要著眼於長期，而非立即解決短缺。
- 兼具美國供應鏈本土化意義：文章指出，與美國格芯合作能讓部分CoWoS關鍵元件在美國生產，回應美國政府對半導體供應鏈本土化的要求，同時避免台積電自行興建新廠所需的龐大資本支出。
- 反映台積電調整垂直整合策略：作者認為，台積電將部分晶圓製造環節外包給其他代工廠，顯示先進封裝需求已大到需要跨廠合作，也反映其對2020年代後期市場需求的長期預期。

## 核心觀點

### 1. 市場波動時，應回歸企業資本回報率與基本面

作者認為，面對AI熱門股票單週下跌20%至30%，投資者應避免被社群媒體的恐慌敘事與槓桿操作氛圍影響。

他強調，理解升息週期、企業選股方法及ROIC（資本回報率），是調整投資組合的重要框架。作者表示，自己先前依據相關邏輯微調持倉，雖無法完全避免下跌，但有助於降低市場波動對組合的影響。

### 2. AI投資應從營收成長敘事轉向現金流與單位經濟效益

作者認為，Anthropic的案例凸顯市場不應只追求持續加速的營收成長，而應關注企業能否透過核心業務產生足夠現金流。

AI實驗室的現金流與算力變現效率，將影響其支付資料中心租金、履行算力合約及維持融資能力的可持續性。合理的估值調整，可能比過高估值下的劇烈修正更有利於AI產業的長期發展。

### 3. 半導體景氣最大風險可能來自集體過度樂觀

作者認為，半導體產業的主要風險不只是技術競爭，也包括各家公司同時根據樂觀需求預測擴產。

ASML的長期訂單策略、SEMI設備支出預測，以及長鑫存儲未來可能增加的DRAM供給，都反映出供需結構的重要性。

即使每家企業的個別擴產決策合理，當新產能集中投入市場，仍可能形成價格下降、稼動率降低及庫存上升的產業週期反轉。
