## 各主題重點

### 主題一｜SpaceX 會與 Tesla 合併嗎？

- 合併具有商業誘因，但公司治理存在重大挑戰。 作者指出，兩家公司已分別成立獨立董事特別委員會，馬斯克也宣稱迴避討論。然而，Tesla 與 SpaceX 存在共同董事 Ira Ehrenpreis，加上馬斯克公開支持合併，可能使董事獨立性受到法律挑戰。

- Tesla 股東表決門檻是合併最大的實際障礙。 馬斯克表示，合併需要全部流通股超過 50% 贊成，而非僅計算出席投票者。由於 Tesla 散戶參與率偏低，棄權或不投票實際上都不利於提案通過。作者指出，先前降低表決門檻的提案僅獲全部流通股 39.4% 支持，顯示通過難度極高。

- 雙方業務與資本支出已高度交織。 Tesla 投資 xAI 的 20 億美元在 SpaceX 併購 xAI 後轉為 SpaceX 股份，雙方另有儲能、汽車及算力相關交易。未來 TeraFab 晶片廠的長期支出可能超過 1,000 億美元，合併有助於簡化成本分攤與內部資源配置。

- 合併可能改善營運效率，但也會集中控制權。 作者認為，Tesla 股東可能獲得換股溢價及參與 AI、太空業務成長的機會；SpaceX 股東則需承擔汽車業務的景氣循環風險。最終結果取決於換股比例、溢價安排及治理程序。

- 合併即使成真，也難以快速完成。 Barclays 推測最快可能於 Tesla 年底股東會前宣布，但多數預期實際交割可能落在 2027 至 2028 年。作者提醒，談判、公平意見書、股東投票及監管審查均可能延宕進度。

### 主題二｜SpaceX 的 AI 收入在爆發？

- AI 業務已成為 SpaceX 最大營收來源。 文章指出，SpaceX 第三季營收達 146 億美元，淨利 44 億美元。其中 AI 部門營收 76 億美元，較上一季的 26 億美元大幅成長，已超越火箭與 Starlink 業務。

- Anthropic 是重要收入來源，但短約設計具有雙面風險。 根據文章，Anthropic 每月向 SpaceX 支付約 12.5 億美元，租用約 32.5 萬顆晶片，單季貢獻約 38 億美元。合約雖名義上延續至 2029 年，但初期過後雙方可提前 90 天通知解約。馬斯克希望藉短約保留算力漲價時重新定價的彈性。

- Anthropic 自建機房可能削弱 SpaceX 議價能力。 作者指出，Anthropic 雖然財務健康，但若未來透過上市融資、自建 5 至 10 GW 的算力設施，對外租賃的依賴可能下降，甚至在續約時要求降低價格。

- 高額資本支出尚未能由本業現金流支撐。 SpaceX 前九個月營運現金流 131 億美元，設備支出卻達 481 億美元。Starlink 所在連網部門第三季獲利 24 億美元，而 AI 部門設備支出達 164 億美元，凸顯資金主要仍仰賴上市募資與舉債。

- 作者認為，馬斯克真正押注的是自家 AI 應用，而非永久出租算力。 SpaceX 利用外部客戶租金及上市資金加速建置電力、機房與冷卻等基礎設施，期望未來 Grok、Cursor 等自家 AI 應用能充分使用現有算力，創造超越租賃收入的價值。

### 主題三｜Nebius 為何要公布 GPU 價錢？

- 公開 GPU 即時租金，是回應市場對資本回收能力的疑慮。 作者指出，Nebius 股價當月下跌近三成後，選擇公開 GPU 即時租金，讓投資人能直接觀察算力市場的定價狀況。

- 新舊世代 GPU 租金出現顯著分化。 美國機房的 B300 供不應求，散客租金曾連續四天維持在每小時 9.0 至 9.4 美元，接近 9.50 美元牌價；但芬蘭機房的 H100 散客價格長期停留在每小時 0.79 美元，與官方 4.50 美元牌價形成鮮明對比。

- H100 低價可能接近甚至低於設備折舊成本。 文章估算，在四年直線折舊下，H100 每顆 GPU 每小時折舊約 0.71 至 1.4 美元，尚未計入電力、冷卻、網路與融資成本。因此，0.79 美元的散客租金可能難以覆蓋完整成本。

- 即時租金不等於整體獲利能力，長期合約覆蓋率才是關鍵。 作者強調，公開價格屬於可搶占的剩餘算力。如果大部分 GPU 已由大型客戶透過長期合約鎖定，低價散客租金影響有限；反之，若大量舊設備只能低價出租，毛利率便可能承壓。公開 API 並未揭露實際成交量與長約占比。

- 算力出租是一場與技術折舊競賽的資本回收遊戲。 作者認為，最新晶片可能持續享有稀缺溢價，但舊款 GPU 會因技術迭代而折價。業者必須趁設備仍具競爭力時，以長約和預付款回收資本支出。

### 主題四｜Meta 拆股的真實意圖，是讓 Zuckerberg 不要離開加州？

- Class C 無投票權股票的設計，不只是為了融資彈性。 Meta 財務長表示，新股類別可用於未來募資或併購，但作者根據 SEC 文件指出，設計最初與 Zuckerberg 的個人稅務及維持公司控制權密切相關。

- 加州財富稅提案引發創辦人流動性與控制權問題。 文章指出，加州 Proposition 40 提案擬對符合條件的高資產居民課徵一次性 5% 財富稅。Zuckerberg 當時約持有 Meta 13% 股權，卻透過 Class B 股票掌握約 60% 投票權，若出售高投票權股票繳稅，控制權可能下降。

- 董事會談判最終形成 1 比 1 配股安排。 Zuckerberg 最初要求每持有一股配發 20 股 Class C，最終降至 1 比 1。其中 20% 的 Class C 可自由出售，其餘 80% 出售時須搭配等量投票股。作為交換，他承諾未來八年留在加州或 Meta 總部所在地，並撤回績效薪酬要求。

- 小股東的治理保障相當有限。 作者指出，特別委員會提出的 Class B 日落條款，以及將配股與財富稅公投結果連結的條件，最終均未保留。交易由掌握 56% 投票權的 Chan Zuckerberg 實體以書面同意通過，小股東沒有實際投票機會，也未獲得類似 Google 當年 Class C 股票設計的折價補償保障。

- 創辦人高度集權同時帶來效率與治理風險。 作者認為，Zuckerberg 的高度控制權使 Meta 能迅速推動 AI 投資與重大轉型，但缺乏有效制衡機制，也可能讓重大錯誤帶來更嚴重的後果。

### 主題五｜SemiAnalysis 說晶片要過剩了？

- 「GPU 過剩」主要指相對於資料中心與電力的供給充裕。 作者強調，SemiAnalysis 原始觀點不是晶片需求崩潰，而是部分客戶已取得 GPU，卻因電力、土地及機房不足，無法立即部署或全速運轉。這與 2022 年需求不足造成庫存積壓的情況不同。

- AWS 的提前接收機櫃流程反映供應鏈時間錯配。 文章指出，亞馬遜短期內向 NVIDIA 提貨約 50 億美元 GB300 伺服器機櫃，部分設備暫存在倉庫或尚未完成供電的機房。作者將此解讀為大型科技企業為確保稀缺硬體供應而提前採購，而非完全沒有需求。

- SemiAnalysis 預測 2027 年資料中心將迎來大規模擴建。 其將全球不含中國的 2027 年新增資料中心容量預測上調至接近 50 GW，依據包括土地、施工許可、電力配置及衛星影像等物理建設訊號。文章提到已有超過 24 GW 項目進入後期施工。

- 晶片訂單可能出現中期空窗期。 作者指出，當庫存 GPU 逐步取得電力並投入使用，新 GPU 訂單可能暫時減速。如果資料中心交付延遲或 AI 需求成長放緩，空窗期可能延長，而未啟用的設備仍持續折舊。

- 2027 至 2028 年可能再次轉為晶片供應瓶頸。 作者認為，若接近 50 GW 的資料中心如期落地，HBM 記憶體與邏輯晶片可能重新成為供應鏈限制。SemiAnalysis 因此強調晶片產能擴張與新晶圓廠設備投資的重要性，而非斷言半導體需求即將崩潰。

## 核心觀點

### 1. 投資不應追求完美擇時，而應重視持倉結構的動態調整

作者認為，對超過 95% 的投資人而言，精準逃頂與抄底幾乎不可能實現。相比頻繁進出市場，他更傾向於持續參與市場，依照估值、風險與產業變化調整持倉結構。

他指出，半導體在市場高度追捧時，對需求端負面消息的容錯率會下降，並不代表長期基本面必然惡化。AI 的投資機會也不應僅限於半導體，而應從不同產業與 AI 基礎設施層次觀察資金變化。

### 2. AI 基礎設施的關鍵是資本回收速度與供應鏈瓶頸轉移

作者認為，SpaceX、Nebius 與 SemiAnalysis 的分析共同呈現 AI 基礎設施的時間差問題。

算力供應商必須在 GPU 折舊與技術迭代之前回收資本；大型科技公司則面臨晶片交貨快、電力與機房興建慢的落差。

因此，局部算力低價、GPU 暫時閒置，以及未來可能再次出現晶片供應緊張，可以同時成立，不應將短期供需錯配直接解讀為 AI 需求結束。

### 3. 強勢創辦人的戰略執行能力與公司治理風險必須同時評估

作者透過 SpaceX、Tesla 與 Meta 的案例指出，創辦人高度掌權能促進企業整合、資本配置與戰略轉型，但也可能衍生利益衝突、少數股東權益受損及治理制衡不足等問題。

企業的成長敘事即使具有商業合理性，最終仍會受到股權結構、法律程序及股東表決規則的約束。

## 創作者建議的觀察方向

### 1. Tesla 與 SpaceX 合併進度

- 股東表決支持率： 留意 Tesla 是否能取得全部流通股過半支持，尤其散戶投票參與情形。
- 特別委員會獨立性： 觀察利益衝突管理、董事獨立性以及公平意見書等程序。
- 交易條件： 追蹤換股比例、Tesla 股東溢價與兩家公司治理安排。
- TeraFab 資本配置： 留意超過 1,000 億美元潛在支出的分攤方式，以及 ASML 財報中與設備需求有關的資訊。

### 2. SpaceX AI 業務的可持續性

- Anthropic 續約與自建機房： 觀察 90 天解約條款、未來租金議價方向及 Anthropic 自建算力進度。
- 現金流與資本支出： 持續比較營運現金流、設備採購與新增融資需求。
- AI 算力回收效率： 追蹤新建機房能否在文章所述的短期回本條件下維持獲利能力。
- 自家 AI 應用發展： 觀察 Grok、Cursor 等應用能否逐步提升自有算力使用率，降低對外部租戶的依賴。

### 3. Nebius 後續財報的三大重點

作者特別提出應在 11 月財報關注：

- 舊 GPU 長約覆蓋率： H100、H200 有多少比例仍受到長期合約保障。
- 長約價格及期限： 每 MW 長約報價是否維持在 2,000 萬至 2,500 萬美元，合約期限是否縮短。
- B300 租金持續性： 美國機房接近每小時 9.50 美元的價格，究竟是短期供需失衡或能維持整季。

### 4. Meta 的股權與治理變化

- Class C 發行後的控制權結構： 關注無投票權股票是否進一步鞏固 Zuckerberg 的控制權。
- Class C 後續配發條件： 觀察股價翻倍、年化報酬率條件所帶來的額外配股可能。
- 小股東保障： 留意無投票權股票折價、潛在權益影響及治理制衡機制。
- 融資用途： 關注新股類別未來是否實際用於募資或企業併購。

### 5. AI 晶片與資料中心瓶頸轉移

- 資料中心完工與通電進度： 觀察 SemiAnalysis 預估的 2027 年近 50 GW 新增容量是否如期交付。
- 閒置 GPU 的消化速度： 追蹤 AWS 等大型科技公司的提前採購設備何時正式投入運轉。
- 新 GPU 訂單成長： 留意既有庫存消化期間，晶片採購是否出現暫時放緩。
- HBM 與邏輯晶片供給： 觀察 2027 至 2028 年瓶頸是否由電力與機房重新轉向半導體供應。
- 晶圓廠與半導體設備資本支出： 持續關注晶片供應鏈擴產能力，以及台積電法說會透露的 AI 基建需求訊號。

### 6. 整體市場與投資方法

- 作者提醒，應定期回顧自身交易紀錄，評估頻繁擇時的實際成果，並根據市場風險變化調整持倉結構，而非只追求短期走勢預測。
