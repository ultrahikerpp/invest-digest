### 一、連假心得：AI 讓外掛自己寫得出來


**作者認為「人生就是不停在打發時間」，重點是找到好玩、有趣、有意義的事。**

作者提到自己過去全年無休，超級討厭放假、期待每天開盤，但這次春節是「高中大學畢業以來第一次這麼 Chill 的農曆新年」。他引述宅男朋友感嘆花太多時間打遊戲時的反射性回答：時間空白的話，找點殺時間的事來做，最後會留下回憶；反而「你在搞哪一隻股票都不一定記得了，只有一開始的幾個代表作記得」。


**作者認為 Vibe Coding 讓「自己做外掛」變成可能，是這個時代的紅利。**

作者回去玩 RO 原始服（四轉前的最古老版本），透過 AI 輔助做出自動喝水等輔助功能。他形容 AI 像「一個非常強的程式設計的朋友」，但仍要花時間讓它搞清楚需求，「並不是弄出來馬上就可以用」。古老遊戲本來根本找不到輔助程式，現在自己就能搞出來。


**作者認為賺錢在這個時代不是特別難的事，健康與感情才是要維持的。**

作者提到看一下全球指數，過去幾年對大家來說「是一個非常非常大的恩惠」，資產被推了一把之後，應該往內心去找真正的快樂。

### 二、連假後開盤：價差 10 點內，資金會慢慢補回來


**作者認為台股大概會開在原地。**

用最後收盤時間看，富台指換算成台指期，價差大概在 10 點以內。若禮拜一國際盤（NASDAQ、日股、韓股）沒有其他變化，「差不多會開在一樣的地方」，也就是 no significant change。


**作者認為接下來一兩個禮拜台股可能有買盤持續回補。**

理由是槓桿型資金、偏交易面的資金、以及找場外金主墊錢的資金，很多在放假前會撤出，之後的一段時間會補部位——「他們不一定會補很快，可是他們就是會補部位」。前提是國際盤沒出大事。


**作者認為美股狀況比較差，本來應該減碼更多。**

作者自述這次是台股減碼比較多，美股只稍微調一點點，因為美股多半是長期持有的「表弟」（長抱標的），比較可惜。整體建議是用放假前的態度面對，不一定要立刻把部位全部靠回來。

### 三、伊朗戰爭風險：不做預言家，但買慢一點賣多一點


**作者認為對伊朗的戰爭可能要發生。**

依據是北約與波蘭領導人都提到希望盡快撤僑，「還在裡面的要趕快閃，不閃之後可能就沒有機會閃了」。作者認為這已經不是暗示，是明示，發生區域衝突的機率就出來了。


**作者認為市場對戰爭沒有「一定會怎樣」的反應模式。**

他以 2022 烏俄戰爭為例：當時大家覺得那只是區域戰爭，現在回頭看指數也都創新高，可是那時候就是跌了一年。至於跌一年是因為戰爭還是其他理由，「到現在都沒有一個真正的結論」——作者自己傾向認為是供應鏈的因素。所以他不會用「這不就大家都知道」的清帥態度去輕忽。


**作者認為具體做法是細微調整，不是砍倉。**

作者說自己不習慣把標的賣掉或大解碼，而是「要買東西就買慢一點，要賣東西就稍微賣多一點」。真正的重點是心理上的 awareness：後面真出事你不會恐慌到把東西賣光，突然突破你也不會瘋狂追回來。

### 四、關稅遭最高法院否決：作者判定是利空


**作者認為關稅退費的機率極低，98–99% 信心指數不會退。**

IEEPA 關稅被最高法院否決，市場禮拜五當利多解釋。但有聽眾在 Telegram tag 他問企業要怎麼把關稅認回來，作者認為「這關稅是絕對不會退的」，剩下 1–2% 可能是個案。理由是：要不要選舉？搞一齣大戲搞到雞飛狗跳，各級官員研究關稅弄個半死，然後跟大家說「不好意思，失誤，從頭來」——機率極低。


**作者認為川普接下來會援引更多法條，關稅照課。**

IEEPA 被擋住，但還有太多已經過多次法律挑戰的工具：232、301，以及最主要拿出來的 122（先給大家一個 10% 之類的 Universal 關稅）。「本來用一個比較大的架構、比較簡單的方式去課大家」，後面會變成比較零碎、碎片化的策略，「這邊弄一點那邊弄一點，反正還是會把你課到家」。


**作者認為這反而墊高不確定性，對市場是 Neutral 到負面。**

本來相對乾淨簡單的關稅架構，要用更多法條去修補，就會產生不確定性。同時本來跟美國沒談好的（加拿大、歐盟）或想站對台的國家，會藉這次訴諸民意、更想跟川普對抗；川普再反擊，對方再不爽再反擊——本來已經告一段落的關稅，又突然搞出不確定性。「我們最可以確定的一件事情，就是市場是不喜歡不確定性的」。


**作者認為看不懂的反彈比下跌更可怕。**

「如果是跌的話，我自己心臟還比較舒服。」作者說賠錢時知道是別人在恐慌亂殺，心中反而踏實；突然莫名其妙開始賺錢反而覺得怪怪的，因為「論理跟推論的過程是非常重要的」。他也自我提醒不做預言家：拿一天兩天的市場反應去講故事，「高機率就會被打臉」。

### 五、資安股被 AI 錯殺：SAST 不等於防護


**作者認為市場對 AI 的態度已經從「過去不相信」擺盪到「過於相信」。**

上禮拜作者才分享資安股應該可以看，這禮拜 Anthropic 推出 Claude Code Security 的資安能力加強，資安股又全部被打下去。作者說過去大家不信 AI 時他一直在 pitch AI 很屌，現在大家要架錘 TPU、架錘各種 AI 取代一切時，他就要去找可行性——「大漲就出來寫一個漲的故事，這真的誰都會，做這種事情是去降低自己的智商」。


**作者認為 Claude Code Security 本質是 SAST（靜態掃描），與資安公司主力方向不同。**

它是靜態偵測程式碼寫完後的漏洞，「有些東西其實在那邊很久還是有一個漏洞在那，只是你沒有注意到」，現在 AI 幫你補起來。但在美股上市的資安公司裡，靜態掃描只是其中一部分的業務佔比，「並不是現在主流去做防護、然後在追求的東西」。市場是用非黑即白的思維直接跳躍解釋成「資安公司都去死」。


**作者以 Cloudflare 與 CrowdStrike 說明差異。**

Cloudflare（長抱標的）重點是擋住暴力流量，之後在 API 取用上面反而受惠，跟 SAST 的故事不衝突。CrowdStrike 則是在 Google、Microsoft 機房的伺服器裡掛一個 APP，本身佔的空間極小卻能做全面防護，主要防的是有人用快速方式突破時能立刻封鎖阻擋——跟「把靜態的 code 弄得更完善」有一定程度的差距。


**作者認為軟體不會死，而是走向 API 化。**

呼應前一波軟體估值調整的邏輯：AI 最主要取代的是 User Interface。老黃在訪問裡也說「軟體要死掉」是很奇怪的說法——你不會為了運貨就重新發明輪子、重新發明推車。以後 ABC 軟體背後功能差不多，過去介面好的（作者舉例：TT、Robinhood 介面好，IB 介面沒這麼好）會是大家的選項，但 API 化時代介面不重要，是讓機器人去用、看 result。計費也從買一堆 seats（不一定用到、佔空間花錢）變成用 result 計費，「對整體的人類來講都是更好的」。Agent Layer 會變成最有議價權的東西，因為它決定要使用哪一個軟體的 API，最後還是會跑出贏家 API。


**作者認為市場常低估新工具帶來的 TAM 擴大。**

援引 Marc Andreessen 的訪問觀點。以模型競賽為例：比誰比較強一兩年前就說過沒意義，「今天你比較強、明天就換別人比較強，只是輪流去當冠軍」。OpenAI 市佔從最大慢慢掉下去，有人當成微軟的疊利多，但作者不這樣認為——市場擴大百倍千倍後，市佔從 80% 掉到 60%、40% 還是賺一大堆錢：「本來 10 塊錢市場市佔 6 成賺 6 塊，今天變 100 塊、市佔 2 成是賺 20 塊」。硬體也一樣：新供應商驗證進去，市場先給獨家供應商天高估值，發現別人要進來就屌殺亂砍、有些直接跌 5 成，可是冷靜後發現伺服器出貨太多，本來就不可能一家吃掉。作者以緯創替 NVIDIA 練功、後面被鴻海去分為例——緯創還是賺得比本來多很多，股價也比數年前高很多。

### 聽眾 QA


**Q：標的會不會漲？（Will Lin：呼籲聽眾別到處問標的會不會漲）**

作者認同這位聽眾。他說自己頂多是「有信心他會漲」，但實際結果超乎預期的很多：光通就爆噴，Lumentum、Coherent、上游的 XTI（逐字稿原文）都表現很好，緯航也賺錢；可是高速的 Astera Labs（逐字稿原文「SR Lab」）「我真的是不知道他在跌什麼，沒有這麼不堪」。作者也提到 AOI 是很多產業內的人重壓的標的，因為他們會在旁邊辦場次，身邊超多人滿倉被搞到賠爆，「然後突然間大家不想搞的時候，幹就噴爛了」。台股他買了一檔很喜歡的軟體股，一年多快兩年報酬基本上是零、停在原地；同期美股的 Palantir 最高時是超級多倍。他原本認為最應該漲的 Confluent（Market Cap 最小、想像空間也大），結果被收購就結束了。結論：用同樣的邏輯與思考做配置，結果就是很難以預期。


**Q：聯電壓七成該不該減碼？（困堡）**

作者說自己比較喜歡先進製程或業界頂尖的東西，這也造成他在景氣循環股、「垃圾翻身」的故事上表現沒這麼好。以聯電來講，「我去看他展望，我不知道你要壓住他什麼樣的故事」——成熟製程要突然大缺，可是中國這邊開這麼多成熟製程。若真的要買成熟製程，作者自己會選世界先進（Vanguard），因為可能吃得到台積電釋出的一些東西。但他補充：「像我這樣的想法，你就跟我反而錯」——說不定聯電後面就大屌噴，甚至一兩年後聯電跑贏台積都有機會。


**Q：記憶體賺到第一桶金後全部出清，對嗎？（Ethan）**

作者說自己沒辦法去做太多行情預測。「記憶體我如果知道他會長成這樣的話，我台股的記憶體我是絕對不會賣的」，但那時還是選擇賣掉去做別的故事。現在看起來如果當時窮抱記憶體可能還好一點，但「拉長看不一定」。他的習慣是不把人生勝負壓在一支標的上，做自己看得懂的部分就 move on。


**Q：平常瀏覽哪些資訊、訂閱哪些內容？（Hong：華爾街日報、Seeking Alpha、富邦證券）**

作者認為這三個「應該是沒有辦法真的把你帶來 Alpha」，可以補充知識但屬中性資訊。新聞很難在裡面找到真的可以大賺錢的東西；Seeking Alpha「某個程度上像是一種加強版論壇」；券商報告則是選擇很多，但有些目標價絕對不會到，有些標的沒人看好卻開始瘋狂漲——他舉聯發科下修時全部券商輪流跟進下修、後面卻大噴、現在大家又要跑回去上修為例，說明券商某個程度上也是人云亦云。他自己有訂 SemiAnalysis，但後來注意到自己的資訊速度跟他們差不多，就不需要再訂。現階段作者越來越「反璞歸真」：**真要研究一個公司的發展，就去看財務數字的變化——持續有在賺錢、持續在成長，這可能是最好的分析。**


**Q：GG 大的近況與持股（H）**

作者說 GG 大已經連續好幾年都有在賺錢，但還是很習慣「大家都說很好是不是？那我就來買一下」然後把它打下去。GG 大最新的嘗試是買了 SNDK 跟美光。SNDK 作者手上沒有所以不在意；美光的話「我覺得他會輸，應該是沒有辦法把我打下去」，而且他買的位置也蠻高的。不過作者自嘲：兩三年前講 Meta 時後來被他搞爆，接著 Google 也說不太可能結果也被打下去。

### 投資心法



- **作者認為看不懂的盤要多打洞、不要壓太大，而不是跟市場對做。** 他自述現在對盤勢「已經是有點處於看不懂的狀態」，身邊朋友也覺得看不懂。做法是「你就多打一點點洞，不要壓得太大，然後去觀察後面的發展」。

- **作者認為市場沒有絕對，反應模式是隨機的。** 「有時候會反應，有時候不會反應，有時候是延遲反應，有時候是提早反應，有時候是過度反應，有時候是反應太少，後面要補跌。」

- **作者認為「賺到錢就是贏家」是錯的，論理與推論過程更重要。** 就算壓錯東西、被估值修正修理，「腦袋維持正確的去判斷一些 Fundamental 的事情」還是非常重要。

- **作者認為就算你贏了市場，槓桿或部位沒控好，最後那個洞還是回不去。** 「我覺得市場在犯錯」跟「我要跟它幹」不一定要劃上等號。

- **作者認為重壓單一標的的人很少，慢慢來比較快。** 觀察身邊厲害的人的 Portfolio，多數是配置 10 檔、15 檔，裡面有輸有贏，長年下來持續賺錢。最大的賠錢往往來自「信仰之躍」——本來穩穩配置有賺，突然覺得「幹就是他了」然後鎖倉爆掉。

- **作者認為「Fake it till you make it」是可以的，大家都從模仿開始。**

- **作者認為不要給別人股票與感情的建議，也不要照別人的建議調整。** 「大家對的時候都會覺得他自己厲害，可是錯了他就會去怪那個給他建議的人。」他強調自己在節目也不給建議，只講自己的想法，投資要相信自己。就算看起來孤立無援也一樣。

- **作者認為市場是動態的，要維持腦袋靈活，別把跌下去的東西當垃圾。** 記憶體以前大家不喜歡，現在是最噴的東西；現在大家覺得 MCU 是垃圾，但作者隱約覺得 **MCU 或被動元件有可能就是下一波的東西**。「過去大家覺得不好的東西，很多時候都會 Sexy Back。」

- **作者認為在恐慌時願意補、在瘋狂追時可以丟一點給人家。** 他以加碼特斯拉為例：覺得 300 是好價格就加，加碼 Range 只有大約 320 到 280 的 40 塊，沒想到會跌到 200 多，直球面又跑到 400–500 大家拼命狂追。「在 300 多往 200 的時候，整個市場一定都在跟你講壞消息；看漲的時候又在那邊吹 Optimus、FSD 要大滲透。」

- **作者認為認為自己是「快樂寶貝」的人通常不是快樂寶貝。** 有意識到自己哪邊做不好、有病識感的人很難是快樂寶貝；「快樂寶貝就是搞不清楚狀況，然後還在那邊大放厥詞」。

- **作者認為投資到後來有點像玄學，努力到極限會發現太多東西不可控。** 他舉例：你 2019、2020 搭好公司底子準備賺大錢、或股票剛賺很多要 All in 說話，結果武漢肺炎跑出來。「人生能夠賺多賺少，好像是有點老天給你的；你只要認真努力一定會賺，只是多跟少不一定。**重點是下檔的風險是可以去控的**——當你想要去 All in 的時候，很多時候都會在那時候幫你上一堂課。」

- **作者認為有本業的人就專注本業，投資把錢配進去慢慢放。** 而「每次在那邊問槓桿的人，其實你們全部都不適合槓桿」。
