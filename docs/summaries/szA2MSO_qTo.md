## 聽眾 QA


**Q：剛進股市要怎麼取得更多市場資訊？**



- 最直接方式是多開幾家券商戶頭，增加可取得的券商報告與研究資料。

- 交易量提高後，可考慮法人部戶頭，取得更多國內外報告、Call Memo 與群組資源。

- 找研究同好分工追蹤不同公司，再彼此交換資訊，能放大有限的注意力。

- 資訊量增加有幫助，但邊際效益會遞減；資料太多反而可能變成 Noise。

- 最終仍要抓住產業大方向與真正受惠廠商，不能把績效完全建立在資訊量上。



**Q：800V HVDC 延後，為什麼相關電源股仍一起下跌？**



- 若 800V 延後，理論上既有 400V 架構受益時間應拉長，不應所有相關標的一起下殺。

- 同樣地，若光學新路線遞延，pluggable 應相對受惠，但實際也同步下跌。

- 因此這波更像修正階段下的市場情緒通殺，而非精準反映單一路線基本面。

- 研發中的 project 本就可能遇到 path finding 或 delay，波動會比成熟量產產品更大。

- 重點是確認延遲是否造成投資邏輯的毀滅性改變；若只是短期衝擊，就不必過度放大。



**Q：被洗出場後，會認錯買回還是換其他標的？**



- 洗出場至今仍常發生，只要觸及停利或停損條件後股價立刻走高，都會被他視為洗出場。

- 過去遇到這種情況較被動，現在則更願意主動追回部位。

- 若原本邏輯仍成立，即使要在較高價格，甚至漲停價重新買回也可以接受。

- 重新買回的部位未必與原持倉一樣大，但核心目標是重新「巴在上面」，避免完全錯過後續行情。



**Q：短線報告造成大跌，該怎麼判斷是否真的影響產業？**



- 先回頭看歷史修正：當時市場反覆討論的利空，很多在股價重新創高後便不再有人在意。

- 不必試圖替每一根下跌找理由，更重要的是判斷消息會不會摧毀長期投資論點。

- 若只是 delay、研發波動或短期市場情緒，就應視為 Noise，而不是直接推翻原有方向。

- 主委以 Astera Labs 為例，股價曾大幅下跌，但若基本面觀察沒有同步惡化，單靠價格不能證明原邏輯錯誤。



## 投資心法



- 估值的重點不是證明當下誰對，而是「估在別人的前面」。

- 便宜不代表會漲，市場願不願意持續進來買才真正重要。

- 價值股與成長股界線並不固定，成長往往只是未來價值提前交易。

- 資訊不是越多越好，過高頻率的正確數字也可能變成 Noise。

- 研究應抓大方向與核心受惠者，不必追逐每一次短期數字上修下修。

- 達到停損或停利條件就執行；若事後證明判斷未變，也要敢於追回。

- 市場修正時先判斷消息是否具毀滅性，短期衝擊不必自動等同趨勢反轉。

- 資金配置可隨市場風格加減碼調整，不必執著自己一定要是價值派或成長派。
