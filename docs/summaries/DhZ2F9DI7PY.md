### 一、AI Agent 能拆解任務，取代一問一答

**對話式 AI 的侷限**　傳統 AI 一次回答一個問題，從既有知識組出答案。Jenny 指出，單問「可不可以買」難以確認數據是否正確，仍須逐一查證。

**Agent 會拆解任務**　Ryan 說明，Agent 會先自問資料來源，例如到 SEC 或第三方金融 API 取得數據，再拆解報表、提煉數字並產出報告。他認為最大差異在於 Agent 的落地，今年年初 Open Claw的出現改變了使用方式。

**投資人的終極目標**　Jenny 的設想是每次丟一家公司給 Agent，就依自訂格式產出報告。她認為單純問 AI「給我幾檔標的」或「幾塊錢可以賣」是錯誤用法，需要一套系統才能跑出有用的數據。

**複製貼上提示語已落後**　過去須自行複製貼上提示語，既落後又麻煩。如今 Agent 會自己找到合適的提示語來執行。

### 二、Skill 以結構化文字檔讓 AI 穩定輸出

**Skill 是純文字檔**　Ryan 說明，Anthropic 在去年 10 月推出 Skill，本質是可結構化、可互相參考的純文字檔。AI 會自行判斷該用哪份文件，例如看財報用財報 Skill，做技術分析用技術分析 Skill。

**解決輸出逐漸變形**　Jenny 觀察早期要求 AI 記住提示語時，第三次執行常開始走樣。有了 Skill 後，格式、內容與資料來源（限權威機構）都穩定遵守，出錯比率明顯降低。

**Salesforce 為例**　Ryan 提到 Salesforce 在法說會公布 200 份 Skill，內含 SQL 語法，讓業務用自然語言即可取資料、建報表。他總結 Skill 實現了「直接與資料對話」，不必再靠工程師層層處理。

**按需拆檔省 token**　Ryan 把財報分析、估值等拆成不同 Skill，策略另寫成獨立檔案。AI 只開啟當次需要的檔案，節省 token 用量。

### 三、五步驟研究流程與 AI 供應鏈 12 層

**先看供應鏈位置**　Ryan 的第一步是判斷公司在供應鏈哪一層、錢跟誰收，再與同層公司比毛利與估值。他把 AI 供應鏈分成 12 層，同層才好比較；例如信越化學與住友化學可比，與台積電則不易比。

**財報細節藏線索**　以 NVIDIA 為例，存貨半年增近五成，其中原料成長兩倍、成品減少兩成，顯示持續進料並快速出貨。他認為這比只看賺不賺錢更能看出上下游關係。

**法說會看未來與情緒**　NVIDIA 首度給出下一年度營收成長七成的指引，隔天股價大漲 8.7%，但目前已回到法說前一日價位。他因此同時蒐集當日與隔日市場新聞，了解市場觀點。

**估值與 Playbook 追蹤**　最後做估值，並用名為 playbook 的檔案記錄公司說過的話與故事線，供後續追蹤，也可用於 CPI 等總經資料。Jenny 補充，估值偏高就放入 Playbook，等機會出現再由 AI 通知。

**官方資料最可靠**　Ryan 的第一類來源是 SEC 與美國勞工局非農就業等免費公開資料，為第一手資訊。財報動輒數十到上百頁（Salesforce 69 頁、Google 77 頁、Microsoft 102 頁、Oracle 117 頁），人難以記全，AI 沒有這個問題。

**成本負擔得起**　美股用 FMP、台股用 FinMind，基本方案各約 500~600 元台幣。他認為遠低於彭博的數萬元月費，且可取代過去其他訂閱。

### 五、課程定位：從 Vibe Coding 邁向 AI Agent

**免寫程式的新階段**　Ryan 說明，去年課程用 No Code 與 Vibe Coding 解決過去寫程式的工作，這次連叫 AI 寫程式都不需要。AI 需要時會自己寫、用完即刪，也不必再用 n8n 等自動化工作流工具。

**回測效率大增**　他指出傳統策略回測可能花一週才發現失敗，用 AI 約 30 分鐘就能判斷有效與否，Agent 更能一次跑多個策略。
