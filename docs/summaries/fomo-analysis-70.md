- 文章回顧，黃仁勳過去三年是產業中最願意為「中國市場應保持開放」背書的人：2023 年公開表態，2024 年赴華府遊說，2025 年與 Trump 談成 H200 輸中、每筆繳 25% 關稅的交易。

### 2. 兩黨共識與 AI Remote Access Rule
- 作者認為，「民主黨反 AI、共和黨挺 AI」是誤解。在限制中國取得先進 AI 技術這件事上，兩黨幾乎沒有分歧，例如 RASA 在眾議院以 369 比 22 通過。
- 文章提到，市場關注八卦的同時，商務部於 11/16 悄悄公布 AI Remote Access Rule，11/19 生效，沒有記者會也沒有辯論。
- 作者以玩具店比喻說明：舊規則管「規格」，業者用 H800、A800 等中國特規版，或透過東南亞 NeoCloud 遠端租用算力來繞過；新規則改管「最終使用者是誰」。
- 文章提到，新規門檻約為 760 顆 H100 或 330 顆 B200，到 Vera Rubin 世代縮至約 72 顆 GPU（一台 NVL72）。晶片搬到哪個國家都沒用，同時新增馬來西亞、新加坡、印尼、泰國、巴西五個高風險國家，並廢除 Biden 時期的 AI Diffusion Rule。
- 作者認為，「晶片所有權」與「算力使用權」可以分開這個前提被拿掉之後，資料中心融資結構、雲端客戶合約、銀行風險評估與 NVIDIA 營收結構都會開始晃動。

### 3. RASA 與國會待審法案
- 文章說明，AI Remote Access Rule 是行政規則，法律基礎較不穩固，可能被修改或廢除；RASA 是法律，會修改《出口管制改革法》，要改動得重走立法程序。
- 文章提到，RASA 目前在參議院銀行委員會排隊。作者以反問暗示，民主黨拿下參議院後較可能加速推進。
- 文章提到，NDAA 中還打包了《Chip Security Act》（晶片位置驗證）、《AI OVERWATCH》（限制直接對中銷售）、《MATCH Act》（針對半導體設備與售後維修）。
