## 投資心法



- 市場修正時，只要強勢族群仍存在，就不必直接推論為全面崩盤。

- 不要因短期跌勢，就把仍有產品與產業展望的族群判定為故事結束。

- 漲多標的位階已高，知道自己買的是什麼，比預測還能漲多少更重要。

- 真正應鎖定的是正確題材，以及未來確實能轉成營收與獲利的公司。

- 市場由全面齊漲轉為強弱分化，反而可能是較健康的多頭結構。

- 交易久了會形成盤感；消息原本打得下去、後來打不下去，本身就是重要訊號。

- 不需要精準抓絕對高低點，但當市場「感覺不對」時，可以重視長期累積出的直覺。

- 題材會輪動，賣掉某個族群不代表看空，只可能是資金轉去交易新的機會。
