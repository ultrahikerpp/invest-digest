## 四、LPU與SRAM先看實際量

**SRAM受惠者有限**

若題材聚焦真正 SRAM，主委認為較直接的對象反而是台積電、三星，因為屬於 On-chip Memory；市場炒作的部分「SRAM 類股」，實際上多為 Pseudo-SRAM，不能直接畫上等號。


**可能歪打正著**

雖然市場第一層解讀可能搞錯產品，但華邦電、愛普仍存在概念相近的新產品。華邦電 Cube 可朝 L3 Cache 應用，愛普 Very High Bandwidth Memory 則嘗試挑戰 HBM 類型需求。
