### 各主題重點

**主題一：Warsh鷹派發言**

- 作者認為，Warsh 從頭到尾沒說「九月必須升息」，但用邏輯鋪陳「Fed 有可能升息」的理由：企業投資動能強（AI 軍備競賽貢獻逾半）、就業未失溫、金融環境不緊縮，同時通膨仍偏高。

- 作者認為，Warsh 必須表現鷹派，是為了回應「財政主導」疑慮——上週財政部長 Bessent 擴大長債回購上限，市場質疑 Fed 貨幣政策會配合財政部發債需求，Warsh 需藉此宣告 Fed 獨立性。

- 作者認為，這場演說本質是「信譽修復」而非升息預告，Warsh 心底真正偏好大概率仍是維持現狀，尤其他是川普欽點的主席，不想一開始就被抨擊。

- 作者認為，九月升息確實因此重新被列入選項，但最終是否升息取決於後續 CPI 與失業率數據，而非 Warsh 的言詞本身。

**主題二：NVIDIA收購Hugging Face**

- 作者認為，若單純用 Hugging Face 約 1.5 億美元年化收入評估，129 億美元收購價（逾80倍收入）非常昂貴，但戰略價值在於它是開發者「找模型、比模型、決定部署方式」的入口。

- 作者認為，NVIDIA 收購後不會擁有平台上的模型權重，真正想掌握的是開發者從「找模型」到「跑模型」這條路徑，最終導向使用 NVIDIA 的 GPU 與雲端算力。

- 作者認為，隨著企業擔憂模型供應鏈資安（如今年7月 OpenAI 內部測試中 AI Agent 曾入侵 Hugging Face 環境），Hugging Face 作為模型「履歷中心」的商業價值將提升。

- 作者認為，這筆交易最大風險與價值同源於「中立性」：Hugging Face 過去曾拒絕 NVIDIA 加碼投資以維持中立形象，若收購後偏袒自家 GPU，開發者社群可能轉向 GitHub、ModelScope 等替代平台。

- 作者認為，最佳策略反而是 NVIDIA 收購後「不要太用力控制」，保留獨立品牌與多硬體支援，靠效能與便利性自然吸引流量。

**主題三：OpenAI 自研晶片 Jalapeño**

- 作者認為，Jalapeño 在跑分測試中擊敗 Blackwell（GB300）某種程度是「應該發生的事」，因為 Jalapeño 用最新 HBM4，對手用上一代 HBM3E，且功耗（700W）遠低於 GB300（1400W）。

- 作者認為，這是「紙面勝利」而非量產護城河：Jalapeño 目前僅是工程樣品，2026年底才小量進機房，真正放量要到 2027-2028年，屆時對手已是軟體迭代過的 Rubin 艦隊。

- 作者認為，Jalapeño 採「平衡晶片」設計（讀題與答題整合、KV cache 鎖在本地），賭的是未來 AI Agent 頻繁任務切換下「狀態不搬家」更具優勢；NVIDIA 則賭「極致分工」（Rubin 讀題、Groq 答題）。

- 作者認為，Jalapeño 從設計到 Tape-out 僅花9個月，OpenAI 用自家 AI 協助設計晶片與撰寫底層代碼（如兩週內用 Codex 生成 MLA 算子程式碼），打破了自研晶片傳統上軟體開發要花數年的「冷啟動詛咒」。

- 作者認為，短期內 Jalapeño 幾乎不會減少 OpenAI 對 NVIDIA 的需求（仍有到2030年約12GW算力承諾），Jalapeño 不對外銷售，主要用途是降低自家推理電費；真正被衝擊的是中期「推論還能否繼續按平台價賣」。

**主題四：Salesforce 暴漲20%**

- 作者認為，這次股價大漲並非營收獲利大幅超預期（營收僅小勝），EPS亮眼主要來自持有 Anthropic 股權重估（貢獻約2.43美元/股）及公司債回購減少股數（貢獻約0.6美元/股），本業EPS若扣除股權重估僅小勝、甚至略低於去年。

- 作者認為，市場重新定價的核心在於「敘事翻轉」：從「AI會取代Salesforce」變成「Salesforce不是受害者」，理由是AI雖擅長理解與整理資料，但缺乏企業內部規則、權限與流程等「上下文」，這些深植於Salesforce系統中。

- 作者認為，Salesforce 新策略是「退讓前端入口、守住後端系統」，推出 Claudeforce 與 Salesforce in Claude 外掛，讓自己成為AI執行商業動作前必經的「神經中樞與執行引擎」，而非爭奪使用者對話入口。

- 作者認為，財報中 Ohalo 案例顯示 AI（如Claude、Cursor）反而可能降低Salesforce導入門檻與時間（原本半年到一年，現在不到一個月），消滅的可能是「導入摩擦」而非Salesforce本身，市場反而可能因此擴大。

- 作者認為，這次大漲能否延續，關鍵在於Salesforce尚未解決「AI如何實質轉化為營收」——傳統按人頭收費模式在AI Agent時代面臨挑戰，公司仍在測試多種計費方案（按Agent數量、API呼叫量或商業成果）。

**主題五：市場對Marvell的不滿**

- 作者認為，Marvell財測上修（2028財年營收指引上修至180億美元）但股價下跌，關鍵在於投資人原本期待與Google的1,200億美元合作案大幅推升2028財年營收，但管理層明確表示真正顯著貢獻要等2029財年及以後。

- 作者認為，1,200億美元屬於「認股權合約」框架下的採購上限，需Google累計採購達門檻才分階段解鎖股權，不能直接視為積壓訂單（Backlog）計入估值。

- 作者認為，2028年財測真正支撐來自資料中心全面加速（光互連、DSP、交換器、客製化本業逾倍成長），而非Google大單。

- 作者認為，市場誤解Marvell搶下Google TPU主晶片，實際合作聚焦於周邊晶片（推論加速器、儲存控制器、網卡、記憶體介面），這類客製化ASIC毛利率顯著低於標準品，導致第三季毛利率指引小幅回落至57.5%-58.5%。

- 作者認為，若Google認股權全數行使將產生約7%股本稀釋，代表營業利益率擴張不等於EPS同步提升，公司需展現足夠回購力道才能回饋股東。

**主題六：混合鍵合再度推遲**

- 作者認為，SK海力士宣布HBM4E不採用混合鍵合，將延續MR-MUF舊工法，混合鍵合登場時間點順延至HBM5（約2029-2030年）。

- 作者認為，主因包括：JEDEC放寬HBM高度上限（從HBM3E的720微米放寬到HBM4的775微米），讓舊工法仍能塞進16層；目前客戶（如Nvidia下一代Rubin架構）尚不需要20層堆疊；混合鍵合設備成本為傳統設備2-3倍且良率未成熟，一層損壞整顆HBM即報廢。

- 作者認為，需區分邏輯晶片與HBM記憶體端的3D混合鍵合：台積電SoIC技術（用於處理器與AI晶片如AMD 3D V-Cache、MI300）進度不受影響，僅HBM記憶體晶片間的垂直堆疊被推遲。

- 作者認為，新技術推遲代表未來兩年HBM供給瓶頸仍卡在晶圓分配與12/16層製造良率，高單價將獲得支撐；Nvidia為確保2027年Rubin Ultra順利出貨,也在考慮推出容量較小(如8層)版本以避免斷貨風險。

- 作者認為，受益者為現有封裝設備廠（Hanmi、ASMPT）及SK海力士、三星等技術護城河廠商，生命週期延長2-3年；Besi與應用材料在HBM混合鍵合的量產敘事時間點延後，但Besi邏輯晶片封裝業務不受影響。
